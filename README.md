## ⚙️ Prerequisites

- GCC
- C++ 20 (Optional, if not use the command above to compile the file)

## 🚀 Installation

```bash
git clone https://github.com/BP1000/Multi-Asset-Electronic-Exchange-and-Algorithmic-Sandbox.git
git checkout exchange
```

## 💻 Usage

```bash
cd src/exchange
g++ -std=c++20 orderbook.cpp -o orderbook
./orderbook
```

## ✨ Features

- ✅ Order Types: Market and Limit Orders
- ✅ Orderbook Functions: fillOrder, killOrder, modifyOrder
- ✅ Orderbook Optimization: Memory Pool
